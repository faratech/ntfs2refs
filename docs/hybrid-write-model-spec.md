## Name
N2RSEL02-H: range-class hybrid journal (format 2) with staged free-destination writes, dual-copy markers, per-granule XXH3-128 table, phase-independent resolver, pinned resource-bounded capacity

## Journal format
CONVENTION (fixes the letter swap between drafts): class A = free destination (staged; destination granule disjoint from the NTFS-allocated set), class B = allocated destination (intersects the NTFS-allocated set, or granule 0, or the post-domain tail, or anything undetermined). N2RSEL01 (selected_journal.rs:10-17) stays untouched; new module src/selected_journal_v2.rs. All counts u64. GRANULE 4096.

[0, 65536) MARKER BODY: 16 slots x 4096. Slot pairs (copy 1, copy 2): HND 0-1 "N2RSHN02"; ABT 2-3 "N2RSAB02"; AP 4-5 "N2RSAP02"; BAR 6-7 "N2RSBR02"; RB 8-9 "N2RSRB02"; slots 10-15 must be all zero. Marker copy bytes (4096): kind [0,8); format u32=2 [8,12); copy_index u32 (1|2) [12,16); immutable_sha256 [16,48); kind digest [48,80) (AP/BAR/HND carry new_all; RB/ABT carry old_B); ticket_sha256 [80,112) (SHA-256 of canonical ticket v2 JSON); zero [112,4064); self SHA-256 of [0,4064) at [4064,4096). Each copy is written as one 4096-aligned write, sync_all, then readback-equal (selected_journal.rs:494-509 pattern); copy 2 only after copy 1 readback. Classification per kind: VALID if either copy equals the expected bytes exactly; ATTEMPTED if neither valid and at least one copy non-zero; ABSENT if both copies zero. Any slot whose non-zero bytes are not a prefix-tear of its own kind's expected marker, or any non-zero reserved slot, refuses as FOREIGN. A slot is only ever written with its own kind: RB never overwrites AP (removes selected_journal.rs:639-644 hazard).

[65536, 65792) HEADER 256 B: "N2RSEL02" [0,8); format u32=2 [8,12); flags u32 [12,16) (bit0 zone_zero_skip; MUST be 0 until the probe gate is recorded, else load() refuses); image_length [16,24); record_count [24,32); segment_count [32,40); granule_table_entries [40,48); bytes_A [48,56); bytes_B [56,64); new_zero_bytes [64,72); old_zero_bytes [72,80); ntfs_allocated_count [80,88); ntfs_table_at [88,96); record_table_at [96,104); segment_table_at [104,112); granule_table_at [112,120); payload_at [120,128); footer_at [128,136); journal_length [136,144); max_journal_bytes (pinned ceiling) [144,152); total_write_bytes [152,160); ntfs_allocated_sha256 [160,192); class_map_sha256 [192,224); header SHA-256 of [0,224) at [224,256).

NTFS-ALLOCATED SET TABLE at ntfs_table_at=65792: ntfs_allocated_count x 16 B (offset u64, length u64), the merged raw.allocated_byte_ranges (ntfs_inspect.rs:197-255) sorted, disjoint, non-adjacent; ntfs_allocated_sha256 = SHA-256(table bytes) and must equal the XXH3-framed set the certificate binds (checked in process at prepare; recovery trusts the immutable pin). Padded to 4096.

RECORD TABLE at record_table_at: record_count x 128 B, sorted, disjoint, 4096-aligned offsets and lengths: offset [0,8); length [8,16); class u8 [16] (1=A, 2=B); old_kind u8 [17] (1=Payload, 2=Zero, 3=GranuleTable); new_kind u8 [18] (1=Payload, 2=Zero, 3=Reference); zero [19,24); old_at [24,32); new_at [32,40); seg_first [40,48); seg_count [48,56); granule_first [56,64); old_sha256 [64,96); new_sha256 [96,128). Rules enforced by validate() and load(): B records have old_kind Payload or Zero (never GranuleTable); A records have old_kind GranuleTable; new_kind Reference requires seg_count>0 and segment lengths summing to length; Payload/Zero require seg_count=0; granule 0 and the post-domain tail are B with new_kind Payload; class = B iff the record intersects any NTFS table entry (recomputed in load(): an A record intersecting the set refuses, a B record not intersecting it and not granule 0/tail refuses); class_map_sha256 = SHA-256 over (offset,length,class) triples in order.

SEGMENT TABLE at segment_table_at: segment_count x 32 B: kind u32 [0,4) (1=Physical device offset, 2=Zero); zero [4,8); source_offset [8,16); zero [16,24); length [24,32). Physical segments must lie inside the NTFS table and outside every A destination; they MAY overlap B destinations (served from that B record's old payload by the resolver). The device-read set D = union(Physical segments) minus union(B destinations), computed by one sweep, must be disjoint from every armed range; D is WritePolicy.retained.

GRANULE TABLE at granule_table_at: granule_table_entries x 32 B: old XXH3-128 [0,16), new XXH3-128 [16,32) of each 4 KiB granule, for every A record and every B record with new_kind Reference, contiguous in record order (record.granule_first, count=length/4096; 0 entries for other B records). Zero granules hash the 4096 zero bytes (no special value).

PAYLOAD AREA at payload_at (4096-aligned): for each record in order: B old payload (if Payload), then new payload (if Payload) for A or B. old_at/new_at = 0 when absent. Zero-kind stores no bytes; check_target still compares byte-for-byte against zeros.

FOOTER at footer_at, 512 B: "N2RSEND2" [0,8); journal_length [8,16); old_B [16,48); new_B [48,80); old_A [80,112); new_A [112,144); new_all [144,176); record_table_sha256 [176,208); segment_table_sha256 [208,240); granule_table_sha256 [240,272); ntfs_allocated_sha256 [272,304); class_map_sha256 [304,336); zero [336,480); footer SHA-256 of [0,480) at [480,512). Framed digests use frame() of selected_journal.rs:85-97 (offset||length u64 LE then bytes) over records of that class in offset order; new_all over all records.

PINS: immutable_sha256 = SHA-256 over [65536, journal_length). SelectedTicketV2 {image_length, record_count, segment_count, granule_table_entries, bytes_A, bytes_B, total_write_bytes, journal_length, max_journal_bytes, immutable_sha256, old_A, new_A, old_B, new_B, new_all, ntfs_allocated_sha256, class_map_sha256, format:2, whole_image_verified:false}. load() verifies in order: length == ticket.journal_length; immutable pin; header fields and self-hash; NTFS table order and hash; record table order/alignment/class rules and hash; segment table containment and hash; granule table hash; every Payload old/new SHA-256; footer self-hash and the five framed digests recomputed from payloads where derivable (old_B, new_B over Payload/Zero; new_A/new_all are rechecked against the device only in check phases). A Reference record's new_sha256 is verified at resolve time (needs the device). Journal length J = 65536 + 256 + pad4k(16K) + 128X + 32S + 32G + pad4k + sum(B old Payload) + sum(B new Payload) + sum(A new Payload) + pad4k + 512, checked u64.

## Write phases
P0 PRE-ACTIVATION (source attributes 3; zero source writes): admission incl. VSS gate; shadow construction and placement (stage 2 adds NTFS-free-first scratch); protected observation; capture with classifier, per-granule XXH3-128 and class accountant; G4 exact sizing; journal preallocated (FileAllocationInfo, EOF 0; allocation.rs:116-121 empty-file check holds); prepare writes [65536,J) then sync_all, then load() re-verifies and the resolver is run once over every Reference record (origins from the frozen source complement handle, hash-checked); ticket v2, plan v2, request, verification, bundle schema 2 saved create_new+sync_all (general_qualification.rs:77-97), then the run directory handle is flushed (FlushFileBuffers on the directory) before activation.
P1 ACTIVATION: certificate.authorize_fresh_apply(proof, ticket) -> LiveApplyToken (binds + class_map_sha256 + ntfs_allocated_sha256 + bytes_A/B + total_write_bytes); activate_for_journal (3->1, RegFlushKey; native.rs:2530-2571, 396-425); arm_phased(PhasedWritePolicy{staged: A ranges, allocated: B ranges, retained: D, total_write_bytes, pinned ceiling}); no content write.
P2 FRESH-APPLY PRECHECK: target.sync_all; check B per byte old-or-new (selected_journal.rs:536-543 rule) AND exact old_B; check every A granule against the granule table AND exact old_A (fresh apply only). Any failure refuses before any marker.
P3 AP: AP.1 then AP.2 (each write, sync, readback). First target write only after AP.2 readback.
P4 STAGED (phase A, policy Staged; may overwrite only A destinations = NTFS-free bytes): per A record, per 1 MiB chunk: read target chunk; each granule must equal old or new XXH3 (neither -> refuse); granules equal to new are skipped; new bytes come from Payload, zeros, or the resolver; each resolved granule is checked against the granule table's new hash BEFORE its write and SHA-256 is accumulated; after the record, accumulated == new_sha256 else refuse (nothing beyond A written; repairable). Then target.sync_all (FlushFileBuffers; handle is NO_BUFFERING|WRITE_THROUGH, native.rs:375-382); read back and verify framed new_A; immutable recheck.
P5 BAR: BAR.1, BAR.2 (write, sync, readback each). Written only after new_A verified.
P6 ADVANCE: policy.advance_to_allocated(): one-way; refuses unless phase==Staged and attributes==1; A disarmed, B armed, retained unchanged.
P7 ALLOCATED (phase B; may overwrite B destinations = NTFS-allocated bytes incl. relocated origins, granule 0 last): write_span rule (selected_journal.rs:556-603) for Payload/Zero new: per byte old-or-new, equal chunks skipped, no per-chunk flush; for Reference new: per granule (bytes == old payload -> write resolved new; XXH3 == new -> skip; else refuse); all B except granule 0; sync_all; granule 0; sync_all; verify new_B, new_A, new_all by readback; immutable recheck.
P8 HND: HND.1, HND.2.
P9 ONLINE: proof.revalidate_backing; shadow state unchanged; bring_online (1->0 with hive flush, native.rs:2682-2699); verify_native_scoped; finalization.json; result.json with free_space_contents_compared=false, free_destination_restored_by_rollback=false, bytes_A/bytes_B, zone_zero_skip=false.
ROLLBACK (AP valid; BAR/RB any): RB.1, RB.2; arm_phased in Rollback mode (allowed = B only, retained = D, maximum = bytes_B); restore B backward (per-byte for Payload/Zero new, per-granule for Reference new), granule 0 last; sync; verify old_B exact; immutable recheck; ABT.1, ABT.2 (digest old_B); bring_online; NTFS mount check. A is never written; its observed framed digest and per-granule old/new/neither counts are recorded.
ABANDON (AP absent or attempted, --rollback): no arming; check B per byte with exact old_B required; observe A granules (non-blocking, recorded); ABT.1, ABT.2; bring_online NTFS.
RESUME (AP valid): load -> markers -> target.sync_all -> check B per byte old-or-new (refuse on foreign byte BEFORE any write; B is NOT required to equal old_B even if BAR is absent, because a lost BAR with durable B writes is a legal state) -> check A per granule (neither -> refuse) -> repair A (P4 rule) -> sync -> verify new_A -> immutable recheck -> BAR.1/BAR.2 rewritten unless already valid -> advance -> P7 -> P8 -> P9.
COMPLETE_HANDOFF (HND attempted): verify new_all, no target write; rewrite HND copies; bring_online; verify. COMPLETE_ABORT (ABT attempted): if RB valid or attempted, re-run the idempotent B restore first; verify old_B; rewrite ABT copies; bring_online NTFS. VERIFY_HANDOFF / VERIFY_ABORTED: verify_closed, no writes.
NATIVE: PhasedWritePolicy phases Staged -> Allocated (one-way) or Rollback (B only). permits() checks only the current phase's set by partition_point. Ordering enforced natively: no B write while Staged, no A write after advance, never a retained write. Ordering enforced only in-process: BAR durability before advance, AP durability before the first write.

## Resolver
Resolver(record, journal, device, policy) serves new bytes for any Reference record identically in prepare, fresh apply, resume, rollback and both completion paths, independent of marker state: (1) Zero segment -> zeros. (2) Physical segment: split at every B record boundary by partition_point over the record table; each part that lies inside a B record is read from that record's old side (Payload bytes at old_at+within, or zeros for Zero kind) in the immutable journal; each part outside every B record is read from the device at its physical offset, and must lie inside WritePolicy.retained (D), which the native gate never writes; a part overlapping an A destination is impossible by validate(). (3) Every resolved 4 KiB granule is compared with the granule table's new XXH3-128 before use; the record's SHA-256 accumulates per chunk and must equal new_sha256 at the end of the record, else refuse (resume keeps protection; rollback for a B-Reference record never needs the resolver because its old side is Payload/Zero and its granule check uses the table). Old bytes: every B byte's old value is its Payload or zeros (never hash-only); every A granule's old value exists only as its XXH3-128 (E2), so rollback never writes A and A old bytes are never needed for any write. Consequence: forward values depend only on the immutable region, zeros, or never-armed NTFS-allocated device bytes; backward values depend only on the immutable region. A changed device byte in D (exclusion breach) is detected by the granule/new_sha256 check and refuses resume; rollback is unaffected.

## Invariants
I1 Class soundness: every changed granule is in exactly one record; A records are disjoint from the NTFS-allocated set stored in the journal; B records intersect it or are granule 0 / the post-domain tail; load() recomputes this from the stored table (no longer a trust-only claim); the certificate binds ntfs_allocated_sha256 and class_map_sha256. I2 Resolver closure: forward bytes come only from the immutable region, zeros, or device bytes in retained D (never armed, native-enforced); backward bytes come only from the immutable region; the resolver is identical in every phase and marker state; every resolved granule is hash-checked before use. I3 Old coverage (E-2): every NTFS-allocated byte any phase writes has Payload or Zero old bytes in the journal; rollback restores the complete NTFS-allocated set and never writes A; staged copies stay in NTFS free space and the evidence says so. I4 Ordering: no target write before AP.2 readback; no B write before A is flushed, new_A verified and BAR.2 read back (in-process) and the policy advanced (native); granule 0 last in both directions; rollback arms B only. I5 Fresh-Apply authority: only LiveApplyToken from the original in-memory certificate; recovery cannot construct one; PreparedClear and ApplyAttempted never resume. I6 Recovery never clears protection: reopen needs attributes exactly 1; the only attribute change is bring_online after a VALID HND or ABT; no repair of 3, no identity change, no rebinding. I7 HND and ABT close replay: any non-zero HND closes rollback; any non-zero ABT closes forward; both non-zero refuse; completion paths verify and write no target byte except CompleteAbort's idempotent restore when RB is present. I8 Markers (E3): write-once per kind, two copies, each self-hashed; a slot holds zero, a tear of its own kind, or its own kind; the intact copy decides; foreign refuses. I9 Content check everywhere (E2): B per byte old-or-new; A and B-Reference per 4 KiB granule old-or-new by XXH3-128; a granule matching neither refuses before any write in both directions. I10 Capacity pins: journal length exact and preallocated before activation; all recovery limits from pins; free space never re-measured after G5. I11 Write authority: armed ranges equal the record table per phase; cumulative bytes <= total_write_bytes; short or failed writes poison the handle. I12 Scope honesty: evidence records free_space_contents_compared=false, free_destination_restored_by_rollback=false, bytes per class, vss_shadow_copies_observed=0, zone_zero_skip=false (until stage 4). I13 Full verification before intent: load() and the complete check pass precede every marker write (unbounded-scale-design.md:834). I14 Refusal before any write: VSS, capacity, class, and token failures all occur with attributes 3.

## Lifecycle table

- **any FOREIGN slot, or HND and ABT both non-absent, or BAR/RB/HND non-absent with AP not VALID (except ABT, see below)** → state: Refused; resume: refuse before reopen; rollback: refuse before reopen
- **all absent** → state: PreparedClear; resume: refuse (fresh apply needs the live certificate); rollback: Abandon: B per byte + exact old_B, observe A, ABT
- **AP attempted, others absent** → state: ApplyAttempted (authority as PreparedClear); resume: refuse; rollback: Abandon
- **AP valid, BAR absent, RB/HND/ABT absent** → state: ApplyIntent; resume: Resume (B foreign check first, repair A, BAR, advance, B, HND); rollback: Rollback (RB, restore B, old_B, ABT)
- **AP valid, BAR attempted** → state: BarrierAttempted; resume: Resume; BAR copies rewritten after new_A verified; rollback: Rollback
- **AP valid, BAR valid** → state: BarrierPassed; resume: Resume (A verify/repair is idempotent; then advance, B, HND); rollback: Rollback
- **AP valid, RB attempted or valid, HND/ABT absent (BAR any)** → state: RollbackIntent; resume: refuse (any non-zero RB closes forward); rollback: Rollback: rewrite RB copies, restore B, old_B, ABT
- **AP valid, HND attempted, ABT absent (BAR any, RB absent)** → state: HandoffAttempted; resume: CompleteHandoff: verify new_all (no write), rewrite HND, online, verify; rollback: refuse (any non-zero HND closes rollback)
- **AP valid, HND valid, ABT absent, RB absent** → state: Handoff; resume: VerifyHandoff then bring_online + verify_native_scoped; rollback: refuse
- **HND non-absent with RB non-absent** → state: Refused; resume: refuse; rollback: refuse
- **ABT attempted, HND absent (AP/BAR/RB any)** → state: AbortAttempted; resume: refuse (any non-zero ABT closes forward); rollback: CompleteAbort: if RB non-absent re-run idempotent B restore; verify old_B; rewrite ABT copies; online NTFS
- **ABT valid, HND absent** → state: Aborted; resume: refuse; rollback: VerifyAborted (old_B, no write) then online NTFS
- **reserved slots 10-15 non-zero** → state: Refused; resume: refuse; rollback: refuse

## Crash table

- **Before activation (admission, VSS gate, placement, capture, G4, prepare, pins, bundle, directory flush)** → durable: Attributes 3; zero source writes; OS-volume artifacts partial; bundle absent or present; resume: none (no bundle, or PreparedClear refused); fresh apply impossible; rollback: refused at reopen (needs attributes 1); NTFS unchanged, stranded at 3 as today
- **Activation flush in flight** → durable: Attributes 3 or 1; PreparedClear; target all old; resume: refuse; rollback: attributes 1: Abandon (old_B exact, ABT, online NTFS); attributes 3: as above
- **AP.1 or AP.2 write in flight** → durable: AP absent/attempted (no target write) or AP valid via copy 1; resume: attempted: refuse; valid: Resume; rollback: attempted: Abandon; valid: Rollback (nothing differs, old_B verified, ABT)
- **Phase A writes in flight, incl. hard power-off mid-chunk** → durable: Attributes 1; AP valid; A granules any mix of old/new/torn; every NTFS-allocated byte untouched (native Staged gate); resume: B per byte (all old), A granules old-or-new (torn -> refuse, protection kept), repair A, sync, new_A, BAR, advance, B, HND; rollback: RB, A untouched by rollback, old_B verified, ABT, online NTFS; A left staged (recorded)
- **A flushed; new_A readback or BAR.1/BAR.2 in flight** → durable: AP valid; BAR absent or attempted; A = new unless flush lost; resume: as above; BAR copies rewritten; rollback: as above
- **BAR lost by dishonest OS-volume flush while B writes landed** → durable: AP valid, BAR absent, B partly new; resume: B per byte old-or-new passes; A verified/repaired via phase-independent resolver (origins under B from journal old payloads); BAR rewritten; B completed; rollback: Rollback restores B from old payloads; exact old_B
- **Phase B writes in flight (granule 0 excluded)** → durable: AP, BAR valid; B per byte old or new, or torn sector; resume: B foreign byte refuses before any write; else A verify/repair, B forward, granule 0, new_all, HND; rollback: RB, restore B backward, granule 0 last, old_B, ABT
- **Granule 0 write in flight** → durable: boot sector old or new per sector; volume has no ReFS identity until this write lands; resume: as phase B row; rollback: as phase B row (granule 0 restored last)
- **All writes verified; HND.1/HND.2 in flight** → durable: target = new_all; HND absent/attempted/valid; resume: absent: Resume (all skipped) then HND; attempted: CompleteHandoff; valid: VerifyHandoff; rollback: absent: Rollback allowed; attempted/valid: refused
- **HND valid; bring_online flush in flight** → durable: attributes 1 or 0; resume: 1: VerifyHandoff then online; 0: refused at reopen (label/mount-path completion not retried, existing gap); rollback: refused
- **RB.1/RB.2 in flight** → durable: RB attempted or valid; AP intact; resume: refused; rollback: rewrite RB copies, continue restore
- **B restore in flight** → durable: RB valid; B mixed; resume: refused; rollback: idempotent re-run, old_B, ABT
- **ABT.1/ABT.2 in flight** → durable: B = old_B verified; ABT attempted; resume: refused; rollback: CompleteAbort (re-run restore if RB present), rewrite ABT, online NTFS
- **ABT valid; NTFS bring_online in flight** → durable: attributes 1 or 0; resume: refused; rollback: 1: VerifyAborted then online; 0: refused at reopen, nothing to do
- **AP lost by dishonest flush after A writes (NTFS still valid)** → durable: PreparedClear; A differs from old_A; B = old_B; resume: refused; rollback: Abandon succeeds (requires old_B only; A difference recorded) -> NTFS online. Fixes verdict-2 stranding
- **AP and BAR lost with B writes durable** → durable: PreparedClear; B partly new; resume: refused; rollback: Abandon refuses on old_B mismatch; stranded at attributes 1 with protection kept (same class as N2RSEL01 today); lab fault --lab-drop-marker qualifies it
- **Fault: device-ref source in D changed (exclusion breach)** → durable: attributes 1; resume: refused at the granule/new_sha256 check before writing that record; rollback: unaffected (old side is journal payload)
- **Fault: NTFS onlined outside the tool during AP state, used, re-offlined** → durable: new NTFS allocations may sit on A destinations; resume: E2 granule table refuses any A granule that is neither old nor new; B per byte also checked; rollback: Rollback restores B; A left as is (recorded); a lab test must prove the refusal
- **Fault: journal immutable region damaged** → durable: attributes 1; resume: load refuses before lifecycle; rollback: load refuses before lifecycle
- **Hard power-off (TurnOff) at any row from AP through ABT** → durable: one of the rows above by the flush points; a marker copy later corrupted is read from its other copy; resume: as the matching row; rollback: as the matching row; physical power loss remains untested (host cache)

## Open risks

- Route destination class split is unmeasured (capture never reached 6,174,015,488): stage 1 may store up to ~6.4 GB of old payload for B routes plus new payload where no copy map is eligible; Need still projects below ~39.7 GB but the margin is unverified.
- Per-granule old-or-new on A and B-Reference is stricter than per byte: a torn 4 KiB granule mixing old and new bytes refuses both directions (resume on A; both on B-Reference) where today's per-byte rule would accept; realistic under physical power loss, unqualified.
- Lost AP and BAR together with durable B writes still strands the volume at attributes 1 (Abandon refuses on old_B); only a lab --lab-drop-marker fault exercises it; physical power loss, lying device flushes and RMW collateral on neighbouring NTFS-allocated bytes remain untested (TurnOff keeps host-cached VHDX writes).
- The VSS online query runs before freeze; a shadow copy created between the query and isolate_observed_ntfs is caught only by the raw diff-area name gate, which cannot see diff areas on other volumes.
- The zone-zero skip needs both the format probe and an authenticated complete ReFS footprint (5,166,432,256 B of the prefix is unaccounted today); the gate stays off and the ~4.9 GB of B-Zero-new old payload remains until then.
- A class-map bug marking NTFS-allocated bytes as A would lose those old bytes on rollback; mitigations are derivation from the digest-bound raw set, recheck in prepare and load(), native bitmap cross-check, and refusal on ambiguity.
- Dual-copy 4 KiB markers rest on FlushFileBuffers honesty of an ordinary NTFS file that is not opened write-through (custom_flags 0x0020_0000 is OPEN_REPARSE_POINT); the hard power-off test must prove the copy semantics as the user required.
- Recovery reads R origins from the source device; a media error on a retained range blocks resume (not rollback).
- Pre-activation stranding at attributes 3, label/mount-path completion never retried after bring_online, and the bundle checksum living only on stdout until result.json are unchanged.
- Every N2RSEL02-H run changes journal, ticket and bundle pins; N2RSEL01 power-off and recovery evidence does not transfer and the full matrix must be requalified on the hybrid build.
- The name N2RSEL02 is also used by docs/unbounded-scale-design.md for a u64 N2RSEL01; the format byte (2) and header magic here are the same string, so that doc must adopt this definition or rename its variant.
- Resume refuses an A record whose accumulated SHA-256 differs from new_sha256 after the granule checks passed (journal/table inconsistency); the state is stranded with protection kept, not corrupted.
